# jubanator — site pessoal

Site pessoal estilo terminal, feito em HTML/CSS/JS puro (sem framework).

## Estrutura
- `index.html`, `style.css`, `script.js`, `content.js`, `terminal-engine.js` — página principal
- `projects/` — páginas individuais de cada projeto (devlogs)

## Rodando localmente
Abra `index.html` com a extensão Live Server do VS Code.
